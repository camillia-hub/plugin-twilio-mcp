# Twilio MCP

Works with Twilio. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/@twilio-alpha/mcp

Installs from the Camillia hub as `twilio-mcp-01c22a`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
